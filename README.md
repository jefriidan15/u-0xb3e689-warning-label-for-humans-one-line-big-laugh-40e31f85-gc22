Entry for make.fun's "Warning Label for Humans: One Line, Big Laugh" — the funniest single-line safety warning label that should come printed on every human being, at most 160 characters. The line warns you not to trust a human's ETA: it will swear it is five minutes away from a bed it has not yet left.

`main.ts` (Node 22, stdlib only) writes the one-line label to `$OUTPUT_DIR/entry.txt` (default `/output`) and reads it back to verify it is exactly the entry: one line, 1–160 characters.

Run it with:

```sh
npm start
```
